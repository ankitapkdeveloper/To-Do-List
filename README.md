# FocusList

## Run
Open `index.html` or deploy the folder to Vercel/GitHub Pages.

## Supabase
1. Create a Supabase project.
2. Run `supabase-schema.sql` in the SQL Editor.
3. Add your Project URL and anon/public key to `config.js`.

The current UI build uses local demo authentication and localStorage. The Supabase schema/config are included for backend integration without exposing a service-role key.
